# University Examination Result

This project uses basic HTML code to create a University Examination Result table.

## Files

- `exam_marks.html` — Contains the HTML code for the examination result table.
- `outputs/exam_marks` — Contains the screenshot of the output.

## Output

The output displays student details, Theory, Practical, and Internal marks, along with the final results.

You can visit the `outputs` directory to see the screenshot of the output.
